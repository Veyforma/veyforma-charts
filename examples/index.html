Charts for the questions risk teams actually ask

Where is exposure concentrated? Which risk factors move P&L? Why doesn't the risk model's P&L match the front office's? When does our debt fall due? Free charts that answer these questions, in plain JavaScript.

  • No dependencies
  • MIT license
  • No build step
  • Keyboard and screen reader
  • Nothing sent to a server
npm install @veyforma/charts
