Which risk factors move P&L the most? Each bar shocks one factor down and up. Diamonds flag convexity (losses that grow faster than the shock), and the contribution view shows which factors drive the combined move and which hedge it.

  VeyRiskTornado.create("#chart", {
    data: {
      prefix: "$", suffix: "m", decimals: 2, limit: 1.5,
      factors: [
        // delta per unit of shock and gamma per unit², with a ±shock
        { label: "USD 10Y rate", group: "Rates", unit: "bp", shock: 25, delta: -0.064, gamma: 0.0006 },
        // or the results of a full revaluation after each shock
        { label: "EUR/USD", group: "FX", unit: "%", shockDown: -5, shockUp: 5, down: -0.48, up: 0.39 }
      ]
    }
  });
</script>
