Exposure Accumulation Map

How much insured value could one event hit? For every point on the map, the chart sums the insured value within the event radius, colours the map by that amount as a share of your limit, and calls out the worst areas by name. Hover anywhere for the exact figure, or click to move the event.

<script>
  VeyAccumulation.create("#chart", {
    data: {
      basemap: VeyAccumulationMaps.usa,
      // [longitude, latitude, insured value, perils: 1 wind + 2 flood + 4 earthquake]
      locations: [[-80.19, 25.77, 120, 3], [-80.12, 26.12, 140, 3], [-95.37, 29.76, 150, 3]],
      areas: [["Miami", -80.19, 25.76], ["Houston", -95.37, 29.76]]
    },
    limit: 2000,   // accumulation limit, same unit as the values
    radius: 100    // event radius in km
  });
</script>
